# Archetype: Agentic AI / AI Systems

**Lead with:** real, hands-on multi-agent system design and orchestration
experience — this is the rarest, most differentiating evidence in the whole
profile, and it's genuine (built and running, not a course project).

**Summary framing:** IT professional with hands-on experience designing and
orchestrating multi-agent AI systems (Claude Code / Cowork), pairing that with
ServiceNow platform depth and a security-operations foundation — able to speak to
agentic AI architecture from direct build experience, not just conceptual
familiarity.

**Skills to prioritize:**
- Claude Code / Cowork multi-agent orchestration and workflow design (built and
  operates a multi-agent career-search system: research, matching, resume-strategy,
  resume-writing, and ATS-scoring agents with defined tool grants, handoff schemas,
  and revision gates)
- Agentic AI, Generative AI (CV-stated specializations)
- AI video generation platform evaluation (Kling 3.0, Mootion 4.0, Veo) for a real
  in-progress venture (Golden Legacy Studios)
- ServiceNow platform skills (Flow Designer, Script Includes) — relevant where a
  posting pairs ServiceNow with Agent Studio / Now Assist / agentic AI scope
- Software development fundamentals (PHP, MySQL, Python, SQL) — relevant for
  AI-integration-engineer-shaped postings that expect some backend capability

**Experience to lead with:** the career-ai agent system itself as a concrete,
describable project (architecture decisions, agent scoping, schema design); current
Accenture ServiceNow role; Golden Legacy Studios AI-tooling evaluation work.

**Certifications to lead with:** none directly AI-specific yet — lead with the
built system as evidence instead of a credential.

**Likely gaps for this archetype:** no formal ML/deep-learning background, no
production-scale AI system experience (this is a personal-use system, not
enterprise-deployed) — name this plainly; "AI Backend Engineer" or similar postings
expecting ML-engineering depth are a real gap, not a fit to stretch toward.
