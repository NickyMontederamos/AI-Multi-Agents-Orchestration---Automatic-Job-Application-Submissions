# Archetype: Security Engineer (General)

**Lead with:** the full breadth of hands-on security exposure across home lab,
real-world PCI DSS/fraud work, and public-facing security education — a
generalist security foundation rather than one narrow specialty.

**Summary framing:** IT professional with cross-cutting security exposure — SOC home
lab operations, real-world compliance/fraud-handling experience from BPO work, and
public cybersecurity education delivery — building toward a broader security
engineering role.

**Skills to prioritize:**
- Cybersecurity Fundamentals, Threat Analysis, Vulnerability Management, Risk
  Assessment and Mitigation, Endpoint Security, Encryption and Data Protection,
  Incident Response Skills (all from CV's stated technical competencies)
- Splunk Enterprise home lab, SOC simulation exercises, email header forensics
- PCI DSS compliance handling, fraud escalation, secure card workflows, real-time
  identity verification (BPO experience — genuine applied-compliance evidence)
- Networking Operations, Cybersecurity Management (CV functional skills)

**Experience to lead with:** Independent Portfolio Projects (home lab), BPO
Customer Experience Analyst (PCI DSS/fraud), Volunteer Cybersecurity Awareness
Speaker (public communication of security concepts — relevant for
consultant/specialist-shaped roles).

**Certifications to lead with:** Google Cybersecurity Certificate series, Cisco
Introduction to Cybersecurity.

**Likely gaps for this archetype:** no formal employment title with "security" in
it yet; no cloud-security-platform-specific certification (AWS/Azure security);
"specialist" or "consultant" framing in postings may expect more independent
client-facing security delivery than currently demonstrated — name this honestly
rather than inflating the BPO/volunteer work to sound like consulting.
