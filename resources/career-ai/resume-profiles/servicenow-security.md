# Archetype: ServiceNow + Security

**Lead with:** the combination itself — real ServiceNow platform experience plus a
self-built security home lab is an unusual pairing most candidates in either lane
don't have.

**Summary framing:** ServiceNow professional (CSA) building explicitly toward
Security Engineer / DevSecOps work by pairing platform depth (Flow Designer, Script
Includes, CSM) with hands-on security operations (SIEM, incident response
simulation) — the stated direction from her own CV, not a stretch.

**Skills to prioritize:**
- ServiceNow: CSA certified, Flow Designer ("Incident Priority Handler" flow),
  Service Catalog Item creation ("GPU Upgrade"), Script Includes, CSM configuration
  (studying CIS-CSM: Config, Data Model, Case Mgmt, Knowledge Mgmt, Workspace), PDI
  hands-on experience
- Security: Splunk Enterprise home lab, SOC simulation exercises, vulnerability
  management, risk assessment and mitigation, incident response skills, threat
  analysis, endpoint security
- Cross-cutting: change management, risk management — both genuinely ServiceNow-ITSM
  and security-relevant

**Experience to lead with:** current Accenture Software Engineer role (ServiceNow
Business Group), Independent Portfolio Projects (home lab).

**Certifications to lead with:** ServiceNow CSA (held), ServiceNow CAD (in
progress), ServiceNow CIS-CSM (scheduled), Google Cybersecurity Certificate series.

**Likely gaps for this archetype:** no ServiceNow Security Operations (SecOps) or
Vulnerability Response module hands-on experience yet — only general platform work;
tenure at Accenture is ~4 months, well under most "X years ServiceNow" requirements —
name this plainly, don't round up.
