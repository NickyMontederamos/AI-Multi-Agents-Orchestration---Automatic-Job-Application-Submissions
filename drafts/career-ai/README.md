# drafts/career-ai/

This folder holds working output from the career-ai pipeline:
- `postings-<date>.md` — raw discovered postings from career-research-agent
- `ranked-matches-<date>.md` — scored/ranked shortlist from career-matching-agent
- `<company>-<role>/` — tailored resume + cover letter drafts from career-resume-agent

Nothing here is final. Final, submittable materials only exist once you've reviewed
a draft and are ready to submit it yourself — this system never submits anything.

Safe to clean out periodically; nothing downstream depends on old dated files still
being present.
